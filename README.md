
# 玄武 WL-X｜轮腿式无人平台系统工程知识探索网站

**XUANWU WL-X — Wheeled-Legged Unmanned Platform**

玄武 WL-X 是一个以轮腿式无人平台为研究对象的交互式系统工程知识探索网站。网站围绕复杂地形环境下无人平台的任务需求、系统组成、运行机制与安全控制，构建从系统认识、需求定义到架构设计的完整知识体系。

通过交互式系统图、需求追溯、运行场景、动态演示与横版闯关游戏，将抽象的系统工程概念转化为可观察、可探索的内容，帮助读者理解复杂无人平台从任务目标到系统实现的设计过程。

---

## 一、网站内容

网站设置三个主要知识板块，并提供互动挑战和演示功能。

### 01｜认识系统 EXPLORE

**从任务构想到系统组成**

以玄武 WL-X 轮腿式无人平台为核心，按照六个层级逐步展开系统分析：

`Mission → SoS → Vehicle → Systems → Subsystems → Modules`

主要内容包括：

- **任务分析：** 了解无人平台的核心任务及典型应用场景。
- **体系协同：** 探索 WL-X 与外部指挥、通信、侦察及保障体系之间的关系。
- **整机构型：** 比较五类轮腿机器人构型，分析不同方案的特点与适用性。
- **系统分解：** 将平台划分为 10 个一级系统、50 个子系统及 203 个末端模块。
- **层级追溯：** 通过交互式结构展示，理解各组成单元的职责与上下级关系。

读者可以通过系统切换、模块搜索、结构展开和平台热点交互，逐步认识轮腿式无人平台的组成与工作原理。

### 02｜定义需求 DEFINE

**从使用场景到工程需求**

围绕 WL-X 在复杂地形中的环境侦察、信息回传和安全运行任务，建立完整的需求分析体系。

| 内容 | 主要研究问题 |
|---|---|
| 业务/任务分析 BMA | 为什么需要这一系统？ |
| 业务需求 BRS | 需要实现哪些业务目标？ |
| 运营概念 ConOps | 不同人员与系统如何协同？ |
| 运行概念 OpsCon | WL-X 在具体场景中如何运行？ |
| 相关方 Stakeholders | 谁对系统提出需求？ |
| 相关方需求 StRS | 如何将使用期望转化为明确需求？ |

通过任务场景、相关方分析、需求规格和追溯关系，展示工程需求从形成到定义的过程。

### 03｜构建架构 ARCHITECT

**从系统需求到控制与安全设计**

基于相关方需求，进一步开展系统需求定义、初始架构设计与系统安全分析。

#### 1. 系统需求规格书（SyRS）

将相关方需求转换为系统功能、性能、接口、安全及质量特性要求，并建立需求来源、架构分配与验证关系。

#### 2. 初始系统架构

展示 WL-X 的主要功能单元、逻辑组成和接口关系，说明感知、计算、通信、运动控制、能源管理与安全监督等部分如何协同工作。

#### 3. 系统控制框图

围绕任务输入、控制器、执行机构、平台运行和状态反馈，展示系统闭环控制的基本原理，并通过不同运行场景观察系统响应。

#### 4. 安全需求与安全架构

结合系统理论过程分析方法（STPA），研究潜在危险、不安全控制行为、安全约束及对应的安全控制机制。

四个部分通过需求编号、功能分配和控制关系建立联系，形成从需求到架构、再到安全设计的完整分析链条。

## 二、互动挑战｜WL-X ADVENTURE

**轮腿探索之旅**

网站提供以 WL-X 为主角的横版闯关互动模块，将机器人运动操作与系统工程知识检验相结合。

互动挑战包括四个主题区域：

1. **轮腿机动域：** 认识平台结构与运动能力。
2. **需求判定域：** 理解业务需求、相关方需求及系统需求之间的关系。
3. **架构控制域：** 探索系统组成与控制原理。
4. **安全约束域：** 了解异常运行与安全控制机制。

玩家通过移动、跳跃、跨越障碍和触发知识终端完成挑战。知识题目来自本地分类题库，根据关卡随机抽取。

### 操作说明

| 操作 | 按键 |
|---|---|
| 向左移动 | `A` 或 `←` |
| 向右移动 | `D` 或 `→` |
| 跳跃 | `W`、`↑` 或 `Space` |
| 与装置交互 | `E` |
| 暂停与继续 | 游戏界面的暂停按钮 |
| 重新开始 | 重开本关 |

游戏提供触控操作区域，方便在支持触摸的设备上体验。

完成挑战后，可以查看得分、知识正确率及对应的反馈信息。

## 三、演示模式｜PRESENTATION MODE

网站提供沉浸式演示功能，用于集中展示系统工程知识与技术图表。

点击页面右上角的 **“演示模式”**，即可进入章节化演示界面。

主要功能包括：

- 章节内容动态展示
- 上一页与下一页切换
- 自动播放与暂停
- 当前动画重新播放
- 演示进度显示
- 全屏演示
- 退出后返回常规浏览

### 演示快捷键

| 按键 | 功能 |
|---|---|
| `←` | 上一页 |
| `→` | 下一页 |
| `Space` | 暂停或继续 |
| `F` | 全屏切换 |
| `Esc` | 退出演示 |

演示模式适用于集中了解平台结构、需求分析和系统架构之间的联系。

## 四、网站使用指南

### 1. 进入网站

通过网站链接打开玄武 WL-X 首页。

首页提供三个主要知识入口：

**认识系统｜定义需求｜构建架构**

点击对应入口即可进入相关知识板块。

### 2. 浏览知识内容

进入板块后，可以通过顶部导航和章节导航切换内容。

部分系统图、需求条目和功能模块支持点击查看详情。

建议按照以下顺序浏览：

`认识系统 → 定义需求 → 构建架构`

这一顺序有助于理解系统工程中从任务目标到系统实现的逻辑关系。

### 3. 探索系统结构

在“认识系统”板块中，可以查看六级系统分解，选择一级系统，继续探索其下属子系统和模块。

在“构建架构”板块中，可以查看系统架构、控制框图及安全机制，理解不同功能之间的交互关系。

### 4. 查看需求与技术文档

在“定义需求”和“构建架构”中，可以浏览需求条目及其来源，查看相关方需求与系统需求之间的关联。

系统需求规格书提供独立的文档阅读入口，便于集中查看需求内容和技术资料。

### 5. 体验互动挑战

点击首页的“开始轮腿探索”或导航栏中的“互动挑战”，进入横版闯关游戏。

根据界面提示控制平台移动，跨越地形障碍，完成知识终端中的问题。

### 6. 使用演示模式

点击右上角“演示模式”，通过控制栏或快捷键切换章节，查看动态知识演示。

## 五、技术实现

网站采用 HTML、CSS 和 JavaScript 构建，通过模块化脚本组织页面展示、交互逻辑与需求数据。

主要功能包括：

- 响应式页面布局
- 多板块内容导航
- 交互式系统结构展示
- 系统需求与追溯关系
- SVG 技术图表
- 运行场景切换
- 系统控制与安全状态展示
- 横版闯关与本地知识题库
- 动态章节演示

网站支持通过 GitHub Pages 进行静态部署，可在现代浏览器中直接访问。

## 八、探索目标

玄武 WL-X 以轮腿式无人平台为载体，将系统结构、需求工程、架构设计与安全分析组织为相互联系的知识体系。

从一项任务为何产生，到系统需要具备哪些能力，再到各项功能如何组织、控制与协同，网站通过可视化、动态演示和互动挑战，让复杂系统工程的设计逻辑变得更加清晰、直观和易于理解。
